# Brock-routed leadership specialist pattern

Use this reference when Jared creates a leadership strategy specialist that should sit behind Brock rather than launching as a standalone bot immediately.

## When to use

- The agent handles high-stakes people leadership moments.
- Brock should frame CEO-level stakes first.
- The specialist goes deep on stance, strategic angles, exact words, and follow-up.
- The work is not HR legislation, formal policy, study, research synthesis, or build work.

## Activation checklist

1. Verify the real canonical Brock soul path before editing. Jared may refer to `brock-soul.md`, but the actual vault file may be `Brock_CEO-Soul.md`.
2. Verify whether the requested specialist files already exist. If they do not, create them at the requested paths rather than assuming the user has attached or placed them.
3. Check for name collisions. Example: `Leo_Leads` is a lead-gen build agent, while `Leo_Leadership` is a leadership strategy agent. Keep routing names distinct.
4. Add the specialist to Brock's `Agent ecosystem Brock operates in` section.
5. Add the specialist to the startup file used by the broader ecosystem, usually `/Users/jc/Desktop/Obsidian/agent-startup.md`.
6. If there is also an Agents folder startup map, update `/Users/jc/Desktop/Obsidian/Agents/agent-startup.md` as a secondary map.
7. Create or update a Hermes setup prompt file for the specialist if Jared supplied prompt snippets.
8. Verify the inserted text and created file paths with file search or reads before reporting success.

## Recommended routing language

- Brock owns CEO-level framing.
- The leadership specialist owns leadership diagnosis, two or three strategic angles, one recommended stance, exact words, what not to say, and follow-up accountability.
- Harry_HR owns legislation and policy.
- Bob_Builder owns builds and automation.
- Sam_StudyNerd owns study.
- Nelly_Notebook owns research and source synthesis.

## Output standards for leadership specialists

The specialist should not provide one script only. It should diagnose first, then compare angles.

Minimum output:

1. Diagnosis.
2. Two or three strategic angles.
3. Recommended stance.
4. Exact language in quotes.
5. What not to say.
6. Follow-up that creates accountability.

Default leadership line:

> Safe enough for truth. Clear enough for performance.
