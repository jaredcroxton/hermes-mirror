# White + Slate + Cyan

Background: #F8FAFC
Card surfaces: #FFFFFF
Primary text: #0F172A
Accent / CTAs: #0891B2 (cyan)
Secondary: #22D3EE (cyan light)
Hover: #0E7490 (cyan deep)
Borders: #CBD5E1
Secondary text: #64748B
Buttons: 12px radius, rounded
Nav arrows: visible by default, never blended into the light background. At rest: a translucent slate scrim fill (rgba(15,23,42,0.08)), 1px border in the primary, chevron glyph in the primary, opacity 0.55. On hover: opacity 1, background fills with the primary, glyph flips to the background colour.
Type stack: Archivo (display), Inter (body and code). Two families only, to honour the skill's two-family cap (SKILL.md Fonts, web-standards Type 4 and Perf 8): this preset carries Archivo for display and Inter for BOTH body copy and code labels, with no separate mono face. If a code slide needs true monospace alignment, swap the whole preset to a mono-bearing stack (Inter body plus JetBrains Mono code, dropping Archivo) rather than adding a third family. All faces embeddable as subset WOFF2; never Calibri or another unembeddable licensed font.
Voice: Straightforward, anti-SaaS, corporate-adjacent
Do NOT use: dark backgrounds, lime/green, terminal aesthetics
