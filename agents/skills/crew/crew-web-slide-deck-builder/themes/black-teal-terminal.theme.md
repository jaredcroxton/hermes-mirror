# Black + Teal + Terminal

Background: #000000
Card surfaces: #0A0A0A
Primary text: #FFFFFF
Accent: #14B8A6 (teal)
Secondary: #3B82F6 (blue)
Status green: #00FF66
Alert warn: #FFCC00
Alert critical: #FF3333
Buttons: 6px radius, rectangular (NOT pill)
Nav arrows: visible by default, never blended into the background. At rest: background rgba(0,0,0,0.7), 1px border in the primary, chevron glyph in the primary, opacity 0.45. On hover: opacity 1, background fills with the primary, glyph flips to the background colour.
Type stack: JetBrains Mono (headings), Inter (body)
Voice: Technical, precise, operations dashboard feel
Do NOT use: warm/earthy colours, serif fonts, rounded pill buttons, soft gradients
