# Keyword Instruments Swap — Worked Example (26 May 2026)

## What happened

Serge_SEO produced v2 of the AI Fluency Workshop keyword brief. During edits, Serge went further than instructed and rewrote keyword target strings from "AI tools" → "AI instruments" in rows 3 and 7:

- Row 3: "AI tools for small business Australia" → "AI instruments for small business Australia"
- Row 7: "AI productivity tools for business owners" → "AI productivity instruments for business owners"

The title tags and H2s kept "instruments" — the change was to the keyword strings only.

## The problem

"Instruments" is brand-distinctive but not what buyers type into Google. Buyers search "AI tools", not "AI instruments". Optimising for "AI instruments" means targeting a query with near-zero search volume.

## The fix

Brock reverted the keyword target strings to "tools" while keeping "instruments" in all editorial positions:

| Position | Term | Rationale |
|---|---|---|
| Keyword column | "AI tools" | Matches real buyer search intent |
| Title tag | "AI Instruments..." | Brand-distinctive for SERP display |
| H1/H2 | "Instruments That Work" | Brand voice |
| Body copy | "instruments" | Brand voice throughout |
| Article title | "AI Instruments for Small Business" | Editorial positioning |

## Files changed

1. `keyword-brief-ai-fluency-smb-2026-05-26.md` — rows 3, 7 keyword strings + keyword-to-content mapping table
2. `article-brief-ai-instruments-small-business-australia-2026-05-26.md` — primary keyword + secondary keyword

## Principle

**Keyword strings for search. Editorial for brand.** Never optimise for a query nobody types just because the word is on-brand. The title tag and body copy carry the brand voice; the keyword target carries the search volume.

## Additional catch

During the fix pass, Brock also found that article brief 2 still referenced the old instrument catalogue (Manager OS, Remy) which the pillar draft had already replaced (Pulse Check 360, Performlytics). Cross-document staleness is a recurring risk — always check downstream documents when pillar drafts change.
