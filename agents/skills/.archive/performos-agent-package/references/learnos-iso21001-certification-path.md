# LearnOS ISO 21001 Certification Path

Use when Jared asks how LearnOS or PerformOS should pursue ISO 21001 certification.

## Key distinction

ISO 21001 certifies the Educational Organisation Management System (EOMS), not the Supabase database or the LearnOS app as a standalone product.

Safe wording before certification:
- "LearnOS is being built around ISO 21001 education-quality principles."
- "PerformOS is preparing an ISO 21001-aligned Educational Organisation Management System for LearnOS."

Safe wording while applying:
- "PerformOS is pursuing ISO 21001 certification for the LearnOS Educational Organisation Management System."

Safe wording after certification:
- "PerformOS operates LearnOS under an ISO 21001-certified Educational Organisation Management System."

Avoid:
- "LearnOS is ISO certified" unless the actual certificate scope clearly supports that claim.
- "Supabase makes LearnOS ISO 21001 certified."

## Supabase role

Supabase certifications support infrastructure, data-hosting, security, and supplier-assurance evidence. They do not certify PerformOS's education management system.

For the ISO 21001 evidence file, Supabase belongs under supplier and infrastructure controls:
- Supabase as hosting/data platform
- Supabase compliance reports and certifications
- data storage location if available
- access control configuration
- backup and recovery position
- sub-processor detail
- PerformOS admin access control
- learner data retention, export, and deletion process

## Where to apply

Do not apply to ISO directly. Apply to an independent certification body that audits against ISO 21001.

For Australia, start with the JAS-ANZ accredited bodies register:
- https://register.jasanz.org/accredited-bodies

JAS-ANZ accredits certification bodies. It does not issue the certificate to PerformOS.

Potential certification bodies to check:
- TUV SUD: ISO 21001 certification and auditing page
- DQS: ISO 21001 certification page
- SGS: check current ISO 21001 scope and Australia/remote availability
- Bureau Veritas: request certification quote
- BSI: check market availability

## Form routing

For TUV SUD or similar enquiry forms:
- Contact Sales, not Customer Support.
- Inquiry topic should be the closest option to "Management Systems Certification".
- If unavailable, use this order: Certification, Auditing and System Certification, ISO Certification, Management Systems, then Training and Education only as a last resort.
- Do not select product testing, inspection, generic customer support, or training course unless the form leaves no better option.

Free-text label:
"ISO 21001 certification enquiry for LearnOS / PerformOS."

## Enquiry copy

Use this short message:

"Hi, I’m enquiring about ISO 21001 certification for an Australian learning technology business. We operate LearnOS, a learning platform supported by Supabase infrastructure, and want to understand the certification pathway for our Educational Organisation Management System.

Can someone confirm whether you provide ISO 21001 certification for an Australian organisation, whether remote audit is possible, and what the expected Stage One and Stage Two process, cost range, and readiness requirements are?"

## Strategic sequence

Do not ask for a full audit first. Ask for a readiness conversation or Stage One quote.

Core scoping question:
"Will you certify a software-enabled learning management system where the Educational Organisation Management System is operated by PerformOS and learner data is stored in Supabase?"

## Related standards

If a site shows related services:
- ISO 21001: correct target for LearnOS education management system.
- ISO 29990: older training-service quality standard. Not the default target.
- ISO/IEC 27001: information security management. Useful later, but not the learning-quality certification.
- ISO 9001: general quality management. Broader and less specific than ISO 21001.
- ISO 9001 Training Courses: training about the standard, not certification for LearnOS.
