# ECU RPL Statement Pattern

Use when Jared asks to build a Recognition of Prior Learning (RPL) statement for ECU Master's units from his professional experience.

## Source documents needed

- Unit outlines from the ECU Handbook (learning outcomes, unit code, unit title, coordinator, description)
- Jared's CV (professional roles, responsibilities, dates)
- RPL cover letter (provided by Jared)
- Original RPL application form (provided by Jared)
- Any relevant certificates Jared uploads

## RPL formatting rules

ECU requires:

- Each learning outcome addressed under its own heading
- Minimum one paragraph per learning outcome
- Must demonstrate how experience meets the specific learning outcome
- Describing activity is not sufficient; must relate experience to the learning outcome
- Cannot rely solely on prior formal learning (credit transfer); must use professional experience

## Critical rule: do not use current study as evidence

When Jared is applying for RPL within his current Master's programme, do NOT cite:

- Any unit from the current Master's as evidence
- Any certificate earned during the current degree (e.g. MIT Professional Education certificate)
- Any assignment, grade, or submission from the current programme
- Any "currently completing" or "currently studying" language

Use ONLY professional experience from before or outside the current degree.
