# Lara Full-Package Pattern

Lara defaults to a single-sheet Excel output when asked for a training session design. To get her complete learning design methodology, the prompt must explicitly request the full standard package.

## Correct prompt pattern

```
Lara, design a [duration] training session on [topic]. Output as a single Excel workbook with your full standard learning design package — all the tabs you normally include in a complete build:

1. Cover — Session title, audience, duration, purpose, author/date
2. Outcomes — Bloom's outcomes with conditions, behaviour, criteria, assessment method
3. Session Plan — Tell-Show-Do-Check segment breakdown with timings, content, activities, facilitator instructions
4. Activities — Each activity: purpose, setup, instructions, timing, debrief questions
5. Assessment — Check-for-understanding per outcome, Kirkpatrick L1 + L2 evaluation
6. Materials — All resources, handouts, worksheets, facilitator equipment
7. Facilitator Brief — One-page summary: flow, timings, must-hit points, pitfalls
```

## What happens without the explicit instruction

Lara produces a single-sheet workbook with session plan only. She may offer a "premium boardroom variant" as an optional extra rather than building the full package upfront.

## Key phrase

"Your full standard learning design package with all the tabs you normally include in a complete build."

This triggers Lara's full methodology. Anything shorter gets the minimal version.
