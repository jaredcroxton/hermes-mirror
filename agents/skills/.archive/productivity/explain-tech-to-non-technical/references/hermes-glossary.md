# Hermes Agent Glossary — Plain English

| Technical term | Plain English |
|---|---|
| Agent | A specialist "employee" the AI calls on to get specific jobs done |
| Brock | The main planner and decision-maker. Think head office. |
| Bob Builder | The builder. He writes code, makes websites, and deploys software. |
| Lara | The training designer. She builds learning programmes and spreadsheets. |
| Sam | The study partner. Helps with university work and course material. |
| Harry | The employment lawyer. Knows workplace law for seven countries. |
| Polly | The product strategist. Handles PerformOS naming and features. |
| Nelly | The researcher. Digests documents and turns them into summaries. |
| Model | The AI "engine" doing the thinking. Currently Owl Alpha. |
| Tokens | How the AI measures language. Like minutes on a phone plan. One token ≈ one word. |
| Cache hit | Reusing stuff the AI already read earlier. Faster and cheaper. |
| Cache miss | New stuff the AI has to read fresh. Costs more. |
| Skill | An instruction manual that tells the AI how to do a specific task properly. |
| Soul file | The file that gives each agent their personality, rules, and knowledge base. |
| SessionDB | A filing cabinet on the computer that saves every conversation Hermes ever had. |
| FTS5 | The search engine that lets Hermes search through all past conversations instantly. Like Googling your own chat history. |
| Cron job | A scheduled task. The AI does something automatically at a set time, like a daily alarm. |
| ACP adapter | A bridge that lets Hermes connect to coding tools like VS Code so you can run AI tasks from inside your code editor. |
| Plugin system | Like apps on a phone. Need a new feature? Plug it in without rebuilding the whole thing. |
| Reasoning content | The AI's "working out." The thinking process stored separately from the final answer. |
| Context window | How much of the conversation the AI can remember at once. Like how much you can hold in your head. |
| openpyxl | A tool for building Excel files using code. Lara uses it for her spreadsheets. |
| learnOS | Jared's training platform where reps complete learning programmes. |
| Build script | A programme that turns markdown files into PDFs automatically. |
| Delegation | Brock handing a job to a specialist agent instead of doing it himself. |
| Sub-agent | An agent spawned by another agent to do a specific sub-task. |
| Gateway | The connection layer between Hermes and messaging platforms like Telegram. |
| Telegram | The messaging app Jared uses to talk to Hermes and the agents. |
| OpenRouter | The platform Jared pays for to access AI models. Shows usage and costs. |
| PerformOS | Jared's side business. Software tools and AI consulting. |
| Accor Plus | Jared's main employer. Sales loyalty programme across seven APAC markets. |
| APAC | Asia Pacific — the region Jared's work covers. |
| Outbound telesales | Calling potential customers to sell memberships. Jared's sales teams do this. |
| Kirkpatrick | A four-level framework for measuring whether training actually works. L1 = did they like it. L2 = did they learn it. L3 = are they using it. L4 = did it improve business results. |
| Bloom's taxonomy | A way of measuring learning from simple recall (remembering) to complex creation (inventing new approaches). |
| GROW framework | A coaching method: Goal, Reality, Options, Way forward. Jared uses it with sales leaders. |
| Sales pillars | The six stages of a Jared's sales call: Connect Early, Clarify Needs, Confirm and Present, Close, Celebrate Belonging, Manage Concerns. |
