# Claude Code brand and cinematic website brief pattern

Use this when Jared asks for markdown that he can transfer into Claude Code to build a PerformOS website, especially cinematic, scroll driven, luxury, 3D, or immersive pages.

## Key learning

Jared may not want Brock to build or deploy the site. He may want a high quality markdown brief that Claude Code can consume directly.

In that case, produce a transferable markdown file or folder on Desktop, then send it as a Telegram `MEDIA:` attachment.

Do not drift into implementation unless Jared asks for a build. The deliverable is the brief.

## Cinematic scroll driven structure

When Jared describes a site as epic, cinematic, scroll driven, fashion film, luxury, immersive, surreal, 3D product showcase, or digital museum, structure it as a scene plan.

Each scene needs:

- job: what this scene must sell or clarify
- visual: what appears on screen
- copy: exact heading, body, CTA, and microcopy
- interaction: what changes on scroll

For the PerformOS Private AI Team offer, an 11 scene structure worked well:

1. Hero, the private AI team arrives
2. Problem, AI is already leaking into the business
3. Answer, a managed AI workforce
4. How the stack works
5. Deployment options
6. Proof of concept pathway
7. Business workflows
8. Governance and control
9. Support model
10. Commercial offer
11. Final CTA

## Nano banana image prompt pattern

If the build may need visual assets, include image prompts for each scene.

Prompt shape:

`A cinematic dark luxury product render of [object], [materials], [lighting], [mood], [composition], 16:9, no text, no logos.`

Use prompts for:

- hero object
- problem backdrop
- agent constellation
- architecture stack
- deployment monoliths
- proof timeline
- workflow wall
- governance vault
- support lane
- pricing objects
- final constellation

If no image generator is available, instruct Claude Code to create intentional CSS placeholder objects, not grey boxes.

## Dark cinematic campaign mode

The default PerformOS brand is light editorial:

- Ivory `#f2efe8`
- Ink `#0a0a0a`
- Electric Lime `#d4ff3b`
- Instrument Serif
- Inter
- JetBrains Mono

For the Private AI Team site, a darker cinematic treatment is allowed because the offer is infrastructure, private AI agents, and managed deployment.

Dark mode is a campaign expression, not a replacement for the core brand.

Keep these anchors:

- PerformOS wordmark rules
- Electric Lime accent
- Instrument Serif headings
- JetBrains Mono labels
- pill CTAs
- short operator first copy

Use cinematic elements as atmosphere:

- fog
- bloom
- floating objects
- reflective surfaces
- scroll morphs
- editorial scale

Do not let the dark style become crypto, cyberpunk, robot hands, or generic AI SaaS.

## Copy guardrails

For these briefs:

- no em dashes
- no fake testimonials
- no fake client logos
- no claim that PerformOS products are deployed unless Jared confirms it
- no guaranteed compliance language
- no zero risk language
- no fully autonomous claims
- spell out one to nine
- numerals for 10 and above
- dates in DD Month YYYY format if dates appear

## Final response pattern

Keep the final response short.

Attach the file first:

`MEDIA:/Users/jc/Desktop/{file-or-zip}`

Then list what is inside in five bullets or fewer.
