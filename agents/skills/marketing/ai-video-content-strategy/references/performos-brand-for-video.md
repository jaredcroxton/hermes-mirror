# PerformOS Brand — For Video Content
## Captured 18 June 2026

## Colours to Use in Every Prompt
| Token | Hex | Video Use |
|---|---|---|
| Ivory | #f2efe8 | Backgrounds, paper textures, clean surfaces, walls |
| Ivory Soft | #e8e4da | Cards, panels, secondary surfaces |
| Ink | #0a0a0a | Text, dark buttons, dark UI, shadows, dark objects |
| Electric Lime | #d4ff3b | CTAs, status dots, highlights, accent glows, the single pulse |
| Ink 60% | rgba(10,10,10,0.6) | Secondary text |
| Ink 40% | rgba(10,10,10,0.4) | Labels, meta |
| Ink 12% | rgba(10,10,10,0.12) | Borders, dividers |

**Rule:** Use Electric Lime sparingly — one accent per scene. Never as a large background area.

## Fonts (Referenced in Prompts)

| Body / UI | Inter | "clean sans-serif" |

**Rule:** "OS" in PerformOS is always italic when written in serif.

## Logo Description (for Prompts)
"Concentric circle mark — dark Ink outer ring, electric lime inner dot. Wordmark 'PerformOS' in Instrument Serif below, with 'OS' in italic."

## Voice in Video Copy
- **Precise:** "One job, done surgically." Not "all-in-one solution."
- **Editorial:** "Volume 01" not "Version 1." "Catalogue" not "product line." "Instruments" not "tools."
- **Confident:** Direct, declarative, active voice. No hedging.
- **Operator-first:** Talk to founders and team leads. Not procurement.
