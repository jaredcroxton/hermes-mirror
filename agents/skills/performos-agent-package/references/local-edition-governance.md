# Local Edition — Google Drive Governance Structure

## Purpose
Every Local Edition client gets a shared Google Drive folder structure for governance, session notes, agent configurations, and ongoing documentation. This is provisioned during onboarding (Week 1).

## Folder Structure

```
[Client Name] — PerformOS AI Team
├── 01 — Governance
│   ├── Service Agreement (SOW)
│   ├── Data Sovereignty Commitments
│   ├── Security Model Overview
│   ├── Approval Gate Configuration
│   └── Audit Log Retention Policy
├── 02 — Agent Configuration
│   ├── Agent Profiles (exported from Hermes)
│   ├── Soul Files (anonymised)
│   ├── MCP Connection Map
│   └── Model Manifest (which models, which agents)
├── 03 — Onboarding
│   ├── Business Needs Questionnaire (completed)
│   ├── Discovery Call Notes
│   ├── Hardware Setup Checklist
│   └── Go-Live Sign-Off
├── 04 — Session Notes
│   ├── YYYY-MM-DD — Monthly Optimization Call
│   ├── YYYY-MM-DD — Quarterly Refresher
│   └── YYYY-MM-DD — Ad-Hoc Sessions
├── 05 — Monthly Reports
│   ├── YYYY-MM — Agent Usage Report
│   ├── YYYY-MM — Performance Summary
│   └── YYYY-MM — Recommendations
├── 06 — Knowledge Bases
│   ├── Company-Specific SOPs
│   ├── Industry Research
│   └── Competitive Intelligence
└── 07 — Training
    ├── Upskilling Course Links
    ├── Certification Pathways
    └── Internal Training Materials
```

## Setup Process
1. Create the folder structure template in your own Google Drive
2. For each new client: copy the template folder, rename with client name
3. Share with client's primary contact (Editor access)
4. Share with Jared's service account (Owner access)
5. Populate with onboarding documents during Week 1

## Naming Conventions
- Dates: YYYY-MM-DD
- Sessions: YYYY-MM-DD — [Type] ([Agent])
- Reports: YYYY-MM — [Type]

## Retention
- Governance docs: life of engagement + 12 months
- Session notes: life of engagement + 6 months
- Monthly reports: rolling 12 months
- Agent configs: current version only (archive previous in subfolder)
