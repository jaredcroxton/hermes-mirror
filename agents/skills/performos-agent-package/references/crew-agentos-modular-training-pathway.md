# Crew and AgentOS Modular Training Pathway

Captured: 15 June 2026

## When to use

Use when Jared asks to turn Crew, AgentOS, AgentOS Academy, Crew Academy, or Claude Code agent training into a programme, website, proposal, PDF, or module pathway.

## Core shift

Do not default to a fixed 12-week course. Jared explicitly preferred moving away from a 12-week framing toward modular capability pathways.

Reason:

- A 12-week programme feels like education.
- A modular pathway feels like an operating system people can use now.
- Crew and AgentOS should be taught through practical capability unlocks, not passive weekly content.

## Structural reference

The Claude Code curriculum site Jared shared is a useful structural model:

- Modular parts rather than calendar weeks
- Short lesson bullets
- Practical build-first outcomes
- Tool-focused visuals
- Clear "what you can do after this" language
- Commercial/build-and-sell framing

Borrow the structure, not the content. Do not copy exact wording, templates, pricing scripts, screenshots, brand language, or proprietary material.

## Two learning pathways

### Crew Academy

Purpose: teach teams how to use Crew through Claude Code to build, automate, review, and ship practical work.

Audience:

- Operators
- Small teams
- Agencies
- Startups
- Internal productivity teams
- Builders who need speed more than audit

### AgentOS Academy

Purpose: teach leaders and technical admins how to deploy governed private AI teams through Hermes, NemoClaw, OpenShell, NVIDIA endpoints, messaging, policy controls, and audit.

Audience:

- Enterprise admins
- HR and compliance teams
- Regulated environments
- Leaders who need governance, audit, and hard boundaries

## Recommended 10-module pathway

### Module 1: Crew Foundations

Outcome: The learner understands what Crew is, how agents work, what a soul file is, and how Brock routes work.

Deliverable: Crew kickoff brief.

### Module 2: Crew Build System

Outcome: The learner can turn a business problem into a build brief and use Bob, Mira, and Nelly to produce a practical asset.

Deliverable: One working business artifact.

### Module 3: Crew Memory and Context

Outcome: The learner understands memory, session search, skills, and context restoration.

Deliverable: Context recovery note.

### Module 4: Crew Agent Workflow

Outcome: The learner can run a request through Think, Plan, Build, Review, QA, Ship, Retro, and Sign-off.

Deliverable: Completed workflow record.

### Module 5: Crew Review and QA

Outcome: The learner can use Quinn and Trace to check whether work is ready to ship.

Deliverable: Review report with pass, block, or needs-work status.

### Module 6: Crew Client Delivery

Outcome: The learner can package Crew outputs for a client or executive audience.

Deliverable: Client-ready delivery pack.

### Module 7: AgentOS Secure Deployment

Outcome: The learner understands NemoClaw, OpenShell, Hermes, NVIDIA model selection, Telegram setup, and sandbox deployment.

Deliverable: AgentOS deployment checklist.

### Module 8: AgentOS Audit and Governance

Outcome: The learner can review gateway logs, Hermes sessions, policy versions, token masking, and allow/deny events.

Deliverable: Simple audit report.

### Module 9: AgentOS Team Rollout

Outcome: The learner can plan a controlled team pilot with access, support, and governance cadence.

Deliverable: Team rollout plan.

### Module 10: Commercial Packaging

Outcome: The learner can explain, package, and position Crew or AgentOS as a business solution.

Deliverable: Client-ready platform explainer.

## Website structure recommendation

Build the training website as a capability map, not a traditional course page.

Suggested sections:

1. Hero: Learn to run a private AI team
2. Crew vs AgentOS selector
3. 10 module cards
4. What you will build
5. Tools used
6. Who each pathway is for
7. Final outcomes
8. FAQ

## Tone rules

Use direct, practical language.

Avoid academic framing and long theory.

Each module should answer:

- What is this?
- Why does it matter?
- What do I do?
- What do I produce?
- How do I know it worked?
