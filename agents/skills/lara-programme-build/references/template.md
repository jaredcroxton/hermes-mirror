# Lara's 16-Column Spreadsheet Template

This is the standard learning-design spreadsheet Lara uses for every programme. It is a SINGLE sheet, not a multi-tab workbook. Every row is one module section. Every column is filled from the source content.

## Column specification (columns A through P)

| Col | Header | What goes in it |
|---|---|---|
| 1 | Section | Section number (e.g. 1.1, 1.2, 2.1) |
| 2 | Module Title | "Module X: [Title]" repeated for all sections in that module |
| 3 | Learning Outcomes | What the learner will be able to do after this section. Action verbs (Bloom's). |
| 4 | Content to be Taught | The raw content — what the section covers. Narrative summary. |
| 5 | Content Sources | Research citations, frameworks, quotes. Everything that backs the content. |
| 6 | Tell (Explain) | The concept explained. The "why" and "what". |
| 7 | Show (Demonstrate) | A worked example, scenario, or demonstration. The "how it looks in practice". |
| 8 | Do - Baseline | The minimum practice activity every learner does. Reproducible. |
| 9 | Do - Creative Alternative | An advanced or alternative practice for learners who want to go further. |
| 10 | Check (Assess) | How learning is verified. Quiz questions (all 4 options + correct answer + explanation) or reflection prompts. |
| 11 | Practical Application | How this section applies on the job. The bridge from learning to doing. |
| 12 | Facilitator / Manager Action | Coaching scripts, session plans, observation cues, reinforcement actions. What the manager DOES with this section. |
| 13 | Duration | Minutes (e.g. "8 minutes (concept 6 min, reflect 2 min)") |
| 14 | Kirkpatrick | Which Kirkpatrick level(s) this section maps to (L1, L2, L3, L4) and the specific indicator. |
| 15 | Evaluation Method | How the Kirkpatrick indicator is measured. Specific method and target. |
| 16 | Notes | Any additional context, dependencies, or cross-references. |

## Styling rules

- Header row: fill #0B1E3D (navy), font Helvetica Bold 11pt white, centered text, auto-filter enabled, freeze panes at A2.
- Data cells: Helvetica 10pt, wrap text, top-aligned, thin grey border (all sides).
- Column widths: not auto-fit. Set explicitly based on content type. Tell and Show columns are widest (55-70 chars). Kirkpatrick and Duration are narrowest (15-20 chars).

## Row count

One row per section, plus one row for Closing. The last row is "Closing: [title]" and covers the programme wrap-up.

For a standard 2-module programme with 7 sections: 8 data rows + 1 header = 9 rows total.

## Sheet name

"[Programme Name] – Lara Design"

Example: "Primer & Question – Lara Design"
