# Piper Prompt Library

Save prompts here only after Jared confirms they worked or after Piper has evidence the prompt produced the intended result.

## Naming convention

`YYYY-MM-DD-domain-model-purpose-v01.md`

Example:

`2026-06-04-image-nano-banana-pro-jr-factory-product-shot-v01.md`

## Prompt record format

- Date.
- Domain.
- Target model.
- User goal.
- Prompt version.
- Result summary.
- What worked.
- What to change next time.
- Copy-ready prompt.

## Rule

Do not save private Accor Plus, employee, candidate, customer, or commercial details unless Jared explicitly wants an internal prompt record.
