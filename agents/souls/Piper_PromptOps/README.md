# Piper_PromptOps

Piper_PromptOps is PROP, the prompting brain of Jared's agent stack.

## Build decision

Option B selected on 04 June 2026: one orchestrator agent plus specialist playbooks. No separate specialist bots.

## Folder structure

- `props-prompt.md`: the master instruction Piper loads to use the playbooks.
- `playbooks/`: specialist prompt playbooks.
- `prompt-library/`: versioned prompts that worked.
- `Piper_PromptOps-Hermes-setup-prompts.md`: two setup prompts ready to paste.

## Active playbooks

- Research and reasoning.
- Image.
- Video.
- Voice and audio.
- Agent and system.
- Marketing and SEO.
- Business strategy.

## Dropped playbook

Learning design prompting was deliberately not built inside PROP. It is folded into Lara_LearningDesign.
