## Security model

- **Least-privilege scoping:** each agent gets only the tools it needs
- **Approval gates:** external emails and record changes require human approval
- **Kill switch:** client revokes MCP tokens → all access terminates in under 60 seconds
- **Audit logging:** every agent action logged (12-month retention)
- **No data storage:** client data flows through their own connections
- **No model training:** client data never used to train or improve any AI model
- **Anti-spam compliance:** Spam Act 2003 (AU), CAN-SPAM, CASL
- **Insurance:** professional indemnity and cyber liability

## Data sovereignty commitments

1. No model training — client data never trains any AI model
2. Local session logs — conversation history on client's own infrastructure
3. Client-owned tokens — client generates and owns all MCP tokens
4. Data residency — agent processing in client's chosen region
5. Right to deletion — complete deletion of agent configurations on request
6. Sub-processor disclosure — Orgo.ai (hosting) and Zapier (tools), both SOC 2
